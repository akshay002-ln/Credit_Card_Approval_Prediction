# 📖 Overview

Banks receive thousands of credit card applications every day. Evaluating every application manually is time-consuming and can introduce inconsistencies.

This project leverages **Machine Learning** to automate the approval process by analyzing applicant information such as income, employment, family status, education, and credit history to predict whether an application should be approved.
